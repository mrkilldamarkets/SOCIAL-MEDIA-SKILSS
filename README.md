# Social Media Skills

The Sovereign Operator skill library by JorDache Darling (@jordachedarling / MrKillDaMarkets): Claude skills for content, growth, brand, capital and operations across 4x Heist, Blue Marlin Securities, HTBB, 4x Prophet and Legacy By Darling.

## Install

```bash
git clone https://github.com/mrkilldamarkets/SOCIAL-MEDIA-SKILSS.git
cp -R SOCIAL-MEDIA-SKILSS/skills/directors/* ~/.claude/skills/
```

Each folder with a `SKILL.md` is one skill. Copy any folder into `~/.claude/skills/` for Claude Code, or zip it and upload it under Settings → Capabilities → Skills on claude.ai.
