# Voice & Copy — TTT Language System

## The Voice

The TTT voice sounds like someone who has already done the work, is still doing the work, and does not need validation to continue.

**Voice qualities:** Direct / Educational / Grounded / Slightly edgy / Human / Precise / Masculine / Practical / Clear

It should never sound: Robotic / Corporate / Soft / Motivational / AI-generated

## Caption Framework

**Line 1 — Hook:** One sentence that stops the scroll. Uncomfortable / Direct / Specific / Contrarian / Emotionally grounded. Never generic.

**Lines 2–4 — Development:** Expand the idea. Context, pain, or story.

**Lines 5–7 — Insight:** Practical takeaway. Make them think differently.

**Final Line — CTA:** One action only. DM "OPERATOR" / Comment "TTT" / Apply through link in bio / Watch the full breakdown / Go to howtobebullish.com

Never use more than one CTA.
