# Content Systems — Platforms, Calendar & Visual System

## Platform Strategy

### Instagram — Primary Visual Home for TTT

The grid should make it clear within 9 posts that JorDache Darling operates through Trade, Train, and Transform.

**Content mix:** Reels 40% / Carousels 30% / Single Photos 20% / Stories daily

**Grid rotation:** Trading post → Training post → Transform/Lifestyle post
No two consecutive posts should feel identical. No same pillar back-to-back without campaign reason.

**Reels:** Trading breakdowns / Gym discipline clips / Nomad lifestyle / Operator insight drops / Proof clips / Short lessons
Length: 30–90 seconds

**Carousels:** Educational frameworks / Trading lessons / Transformation systems / Lifestyle architecture / Operator protocols
Length: 8–12 slides. Use the standard 10-slide framework:
Slide 1 (Hook) → Slide 2 (Problem) → Slides 3–8 (Education) → Slide 9 (Summary) → Slide 10 (CTA)

**Stories — daily:**
Behind the scenes / Market updates / Gym check-ins / Food / Travel / Real-time operator life / Polls / Q&A / DMs / Proof

## Visual System

### Primary Color Palette

| Name | Hex | Usage |
|---|---|---|
| Deep Navy | #0D1B2A | Primary backgrounds, institutional feel |
| Rich Gold | #C9A84C | Accents, numbers, hooks, CTAs |
| Pure White | #FFFFFF | Primary text on dark |
| True Black | #0A0A0A | Deepest backgrounds |
| Slate Grey | #B0B8C1 | Secondary text, dividers |

### Visual Mood

Dark is default. Aesthetic should feel: cinematic / institutional / premium / clean / masculine / controlled / operator-level

**Avoid:** Cheap templates / Loud colors / Cartoonish icons / Fake luxury / Cluttered designs / Motivational-poster aesthetics

### Typography Rules

- Clean sans-serif for body copy
- Bold condensed text for hooks
- Gold for numbers and stats
- Uppercase for major hooks
- Title case for body overlays

### Overlay Rules

- Maximum three lines of overlay text at one time
- Gold text on dark background
- White text on outdoor/natural content
- Never put URLs in video overlays (use caption or bio)
- TTT watermark in lower right corner for branded personal content

## Content Quality Filter

Before any piece of content is published, run this check:

```
1. Which pillar is this?              Trade / Train / Transform / Mixed TTT
2. What is the audience pain?         [Identify specific pain from the list below]
3. What is the operator lesson?       [One clear insight]
4. What should the audience do next?  [One CTA only]
5. Does this sound like JorDache or generic AI?  [If generic: rewrite sharper]
```

**Audience pain list:**
Losing trades / No structure / No discipline / Failed prop accounts / Weak body / Poor environment / No direction / Lifestyle inflation / No leverage / No capital architecture / Profitable but directionless

**Signs it sounds generic (rewrite triggers):**
- Starts with "Most people..."
- Contains any banned phrase from voice-and-copy.md
- Could have been written by a random trading account
- Doesn't contain a specific operator detail, number, or real situation
- Ends with a vague CTA or multiple CTAs
