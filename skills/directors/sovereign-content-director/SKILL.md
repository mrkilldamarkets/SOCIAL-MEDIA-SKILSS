## Platform Frameworks

### Carousel (Instagram / LinkedIn)

```
Slide 1  — Massive hook. Pattern interrupt. Strong visual. Minimal text.
Slide 2  — Problem / Pain point / Current reality
Slide 3  — Why it happens / Root cause
Slide 4  — Framework / Visual diagram / Model / System
Slide 5  — Step 1
Slide 6  — Step 2
Slide 7  — Step 3
Slide 8  — Common mistakes
Slide 9  — Summary framework / Visual recap
Slide 10 — CTA (simple, direct, no begging)
```

### Reels / TikTok

```
First 3 seconds — Curiosity / Shock / Pain / Desire / Contrarian view
Middle          — Education / Proof / Framework / Insight
End             — Simple CTA: Comment / Follow / DM / Save / Share
```

### Caption Structure

```
Hook
↓ Problem
↓ Insight
↓ Solution
↓ Lesson
↓ CTA
```

Tone: Operator. Direct. Educational. Human. Professional. Grounded.
