# Alignment Tools — Coordination, Resources & Visibility

## Strategic Alignment Framework

Every initiative across every brand must map back to one of the two master frameworks:

**40 Before 30** — The life operating system
**9-Month Operator Wealth Plan (May 2026 – Feb 2027)** — The active mission window

Before any initiative gets resources, map it:

```
INITIATIVE:                [Name]
40 BEFORE 30 PILLAR:       [Wealth / Fitness / Travel / Family / Business / Freedom / Legacy]
9-MONTH PLAN OBJECTIVE:    [Scale Revenue / Grow Media / Expand Capital / Build Systems /
                            Travel Asia / Relocate to Bahamas / Increase Leverage]
CONTRIBUTION:              [How specifically does this advance the mapped objective?]
MISALIGNMENT FLAG:         [Does this conflict with any current priority?]
```

If an initiative cannot map to either framework — it is not a priority. It may be interesting.
It is not a priority.

## Resource Allocation Decision Framework

When two priorities compete for the same resource (time, capital, or attention):

```
RESOURCE CONFLICT:    [Resource in contention]
OPTION A:             [Initiative A] — Priority Level [1–5] — Revenue Impact: $[X]
OPTION B:             [Initiative B] — Priority Level [1–5] — Revenue Impact: $[X]

EVALUATION:
  Which produces faster revenue?         [A / B]
  Which builds a more durable asset?     [A / B]
  Which aligns closer to 9-Month Plan?   [A / B]
  Which has a harder external deadline?  [A / B]
  Which is harder to restart if paused?  [A / B]

DECISION:             [A / B / Split / Sequence]
RATIONALE:            [One sentence]
DEFERRED ITEM:        [What gets pushed + revised timeline]
```

**Default rule when deadlocked:** Choose the option that generates revenue first.
Infrastructure and brand initiatives can wait. Revenue cannot.

## Initiative Intake Process

When a new idea, opportunity, or request arrives — run this triage before committing resources:

```
INTAKE TRIAGE:

Name:                  [Initiative name]
Source:                [Who proposed it / where it came from]
Type:                  [Revenue / Asset / Infrastructure / Brand / Experimental]

Quick Filter (answer all five — if any is No, deprioritize):
  □ Does this align with current 9-Month Plan priorities?
  □ Do we have the resources to execute this without sacrificing existing P1/P2 work?
  □ Is there a clear owner available?
  □ Can we define success in measurable terms?
  □ Would we still want this in 6 months?

If passes filter:
  Priority Level:        [1–5]
  Earliest Start:        [When resources are available]
  Assigned to:           [Owner]
  Added to:              [Project tracker]

If fails filter:
  Disposition:           [Kill / Park for later / Revisit in [month]]
  Reason:                [One sentence — honest]
```

**Volume rule:** No more than three Priority 1 initiatives active simultaneously.
If a fourth Priority 1 item appears — something else must drop or complete first.

## Founder Focus Protection Protocol

The most constrained resource in the organization is JorDache's attention.

Every request for JorDache's direct involvement should be evaluated:

```
DOES THIS REQUIRE JORDACHE?

Can it be delegated to a skill/department?     → Delegate
Can it be automated?                           → Automate
Can it wait until a defined decision window?   → Batch it
Does it require JorDache's judgment or voice?  → Approve and schedule
```

**Batch decision windows:** Group non-urgent decisions into defined weekly slots
rather than allowing constant context-switching. Protect deep work blocks.

**Protected time (non-negotiable):**
- Trading sessions (Asia, London, NY as applicable)
- Content creation blocks (filming, writing)
- Physical training (competition prep is a brand and health priority)
- Strategic thinking time (unscheduled — this is where the best decisions come from)

No meeting, request, or initiative should encroach on protected time without JorDache's
explicit approval.
