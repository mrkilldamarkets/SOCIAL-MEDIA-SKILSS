# Blue Marlin Securities — Visual Identity System

## Color Palette

| Name | Hex | Usage |
|---|---|---|
| Deep Ocean Blue | #071A35 | Primary background, hero sections |
| Midnight Navy | #0B1220 | Dark panels, card backgrounds |
| Abyss Blue | #102A43 | Secondary backgrounds, layering |
| Marlin Blue | #114B8C | Accents, interactive elements, glow |
| Gold | #D4AF37 | Primary accent, CTA elements, logo mark |
| Soft Gold | #F4D35E | Hover states, secondary highlights |
| Pure White | #FFFFFF | Typography, high-contrast elements |

**Color rules:**
- Never use white backgrounds
- Never use bright colors outside the palette
- Gold is reserved for high-value UI moments — use sparingly
- Depth is achieved through layering blue values, not adding new colors

---

## Typography System

**Philosophy:** Luxury Editorial meets Institutional Modern. High contrast. Elegant. Minimal.

**References:** Financial Times / Bloomberg / Private Banks / Luxury Automotive / Modern Architecture Firms

**Hierarchy rules:**
- Headlines: Large, confident, generous tracking, minimal weight
- Body: Tight, precise, never cramped — always breathing room
- Labels/Captions: Uppercase, wide tracking, gold accents
- Never use more than two typefaces in a single asset

---

## Design Principles

Everything must feel: Cinematic / 3D / Immersive / Modern / Expensive / Minimal / Premium / Sophisticated / Deep / Purposeful

**Spatial system:** All layouts use layered depth — foreground, midground, background. Never flat.

**Motion principle:** Everything moves with intention. Slow reveals. Deliberate transitions. Nothing bounces.

---

## UI Component System

### Glass Cards
- Frosted glass panels over deep blue environments
- Subtle border: 1px, rgba(255,255,255,0.08)
- Background: rgba(255,255,255,0.03–0.06)
- Backdrop blur: 12–20px
- Soft shadow: 0 8px 32px rgba(0,0,0,0.4)
- Every card should feel like a secure financial terminal

### Floating Panels
- Layered above background at multiple Z-depths
- Gradient lighting from above or side
- Micro interactions on hover: subtle lift + glow
- Never static — always breathing

### Gradient Lighting
- Source: Top-left or top-center
- Color: Marlin Blue (#114B8C) fading to transparent
- Use to create depth, never decoration

### Particle Systems
- Fine, slow-moving particles suggesting depth and data
- Not decorative — should evoke ocean depth or data networks
- Density: sparse. Motion: near-imperceptible drift.

## Image Direction

**Approved themes:**
- Deep ocean / underwater environments
- Blue Marlin in motion (distant, powerful, never cartoonish)
- Water particles and light refraction
- Luxury architecture and financial districts
- Global infrastructure and trade routes
- Technology networks and digital capital systems
- Satellite and aerial views
- Institutional environments (trading floors, research rooms)

**Forbidden:**
- Cartoon graphics or flat illustrations
- Stock finance photos (men in suits pointing at charts)
- Crypto imagery or neon aesthetics
- Fake luxury (Lamborghinis, champagne, watches)
- Dollar signs or generic money imagery
- Charts overlaid on everything
- Retail trading graphics
- Template website aesthetics

---

## Logo & Mark Philosophy

The Blue Marlin mark should evoke: Speed in stillness. Institutional power. Ocean mastery.

Never make the logo loud. It doesn't need to shout — it needs to be unmistakable.
