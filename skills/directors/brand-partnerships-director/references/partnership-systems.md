## Media Partnership Framework

### Podcast / Interview Appearances

**Qualify before committing:**

```
PODCAST EVALUATION:

Show Name:
Host:
Audience Size:          [Downloads or listener estimate]
Audience Profile:       [Who listens — does it match our target audience?]
Host Credibility:       [Would being associated with this host strengthen or weaken positioning?]
Content Standard:       [What does a typical episode look like? Is it substantive?]
Topics Available:       [What would we discuss — does it align with operator narrative?]
Distribution:           [What platforms, email list size, social following]
Five-Year Test:         [Would this appearance still look credible in 2031?]
Decision:               Accept / Decline / Counter-propose
```

**Appearance brief (pre-interview):**
- Core story thread: Operator building a global capital business and media ecosystem
- Key talking points (3 maximum): sequential leverage model / "give education free, monetize capital" / 40 Before 30 as life operating system
- Topics to avoid: specific return claims / predictions / retail trading framing
- Desired outcome: authority positioning + one ecosystem entry point mentioned naturally

## Sponsorship Framework

Every sponsorship must feel: Natural / Aligned / Authentic / Strategic / Valuable

**Never:** Purely transactional sponsorships that the audience can feel are just paid promotions

**Evaluation for any sponsorship:**

```
SPONSORSHIP EVALUATION:

Brand:                  [Name]
Product/Service:        [What they sell]
Audience Fit:           [Does this solve a real problem for our audience?]
Brand Alignment:        [Does this brand strengthen or weaken our positioning?]
Usage:                  [Do we/would we actually use this?]
Compensation:           $[X] per [post/video/month]
Deliverables:           [What they require — volume, format, approval rights]
Exclusivity:            [Any restrictions on competing brands?]
Disclosure:             [FTC/advertising disclosure requirements met]
Five-Year Test:         [Would this sponsorship look credible in 2031?]
Decision:               Accept / Decline / Negotiate
```

**Authenticity rule:** Only sponsor products that solve real problems for the audience.
The moment the audience senses sponsored content is purely transactional — trust erodes.

## Affiliate Philosophy

Recommend products because they solve problems. Not because they pay commissions.

**Affiliate evaluation:**
1. Would this be recommended without a commission? If no — do not affiliate.
2. Is the product/service quality something to be genuinely confident about?
3. Is the commission structure fair — or does it create perverse incentives to oversell?

**Affiliate disclosure:** Always clear. Never buried. The audience's trust is worth infinitely more than any affiliate commission.

## Negotiation Philosophy

**Protect:** Brand / Audience / Reputation / Leverage / Long-Term value

Never negotiate from desperation. The moment desperation is sensed — leverage shifts.

**Negotiation principles:**
- Know the walk-away before the conversation starts
- Lead with value, not price
- Silence is a negotiation tool — use it
- Never accept the first offer on anything significant
- Get everything in writing — verbal agreements are not agreements

## Partnership Lifecycle Management

**Monthly:** Review all active partnerships against KPIs

```
PARTNERSHIP REVIEW — [Partner] — [Month]

Agreed Terms:           [What was promised by each party]
Delivered:              [What actually happened]
Revenue/Value:          $[X] generated
Audience Response:      [Positive / Neutral / Negative]
Issues:                 [Any problems to address]
Recommendation:         Continue / Optimize / Escalate / Exit
```

**Exit criteria:** Remove any partnership that:
- Creates reputational risk
- Fails to deliver on agreed terms for two consecutive months
- No longer aligns with positioning evolution
- Audience responds negatively to

**Exit cleanly:** Honor contractual obligations. Never burn bridges publicly.
The trading and finance community is small — how exits are handled is remembered.
