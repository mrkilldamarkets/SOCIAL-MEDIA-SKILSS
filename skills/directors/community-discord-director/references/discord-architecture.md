# Discord Architecture — Channels, Design & Moderation

## Discord Philosophy

Discord should feel like a professional trading floor.
Not a gaming server. Not a meme community. Not social media.

Every channel has a clear purpose, a defined outcome, minimal clutter, high signal, and low noise.
Members should know exactly where to go for exactly what they need — with zero confusion.

## Trade Review Format (Required for #trade-reviews)

```
Asset:          [e.g., XAUUSD]
Direction:      [Long / Short]
Setup Type:     [OB retest / Liquidity sweep / FVG fill / etc.]
Entry:          [Price]
Stop:           [Price]
Target(s):      [Price(s)]
Outcome:        [Win / Loss / Break-even — with result in R or $]
Thesis:         [Why this trade made sense before entry]
What worked:    [Honest assessment]
What didn't:    [Honest assessment]
Would I take again? [Yes / No / Modified — explain]
```

No complaining about losses. No blaming the market. Just process.

## Channel Design Principles

- **High signal, low noise** — if a channel is consistently low-quality, pin a reminder or reorganize
- **No double-posting** — one idea, one channel
- **Thread usage** — long discussions go in threads, not the main channel feed
- **Pinned messages** — every channel has a pinned post explaining its purpose and rules
- **Emoji reactions** — used for acknowledgment to reduce message clutter (✅ for confirmed, 🔥 for wins)

## Moderation Standards

### Response Hierarchy
1. Self-moderation — members uphold standards
2. Community Leaders / Ambassadors — first line of response
3. Moderators — rule enforcement
4. Noah Bush — community management escalation
5. JorDache — culture-level decisions and final calls

### Violation Ladder
| Violation | First Offense | Repeat |
|---|---|---|
| Low-quality post (no thesis on trade idea) | Reminder + request to edit | Warning |
| Hype / signal-group energy | Direct message + public reminder | Removal |
| Negativity spiral / victim energy | Private message + challenge | Warning then removal |
| Personal attacks or disrespect | Immediate timeout + warning | Permanent removal |
| Promoting other communities or services | Immediate removal — no warning | Permanent |
| Guaranteeing returns to others | Immediate removal — no warning | Permanent |

**Response tone:** Firm and fair. Never public shaming. Direct correction, not humiliation.

### Culture Drift Detection
Watch for gradual degradation:
- Members posting results without process context (hype energy creeping in)
- "When will we get signals?" questions increasing
- Accountability channel going quiet
- General channel dominating over trading channels

**Response:** Increase recognition of process-first behavior. Feature a transformation story.
Address directly in #announcements if drift is widespread.
