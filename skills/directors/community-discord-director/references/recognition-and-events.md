# Recognition, Gamification & Community Events

## Recognition Philosophy

Celebrate the process as loudly as the result.

A funded pass is celebrated. A 90-day journal streak is celebrated just as loudly.
The community learns what is valued by watching what gets recognized.

If we only celebrate payouts — members optimize for payouts.
If we celebrate discipline, consistency, and process — members optimize for becoming operators.

## Award System

Awarded monthly or quarterly by staff vote + community input:

| Award | Criteria |
|---|---|
| Consistency King | Longest active journal streak in the period |
| Biggest Payout | Largest single withdrawal in the period |
| Best Trade | Best documented trade (setup + execution + review quality) |
| Top Monthly Performer | Best risk-adjusted returns with documented process |
| Challenge Destroyer | Fastest prop firm evaluation pass with clean process |
| Elite Operator | Most consistent application of the Operator System framework |
| 100 Trades Executed | 100 documented trade journal entries |
| Risk Management Award | Best example of capital preservation and drawdown management |
| Community Impact Award | Most positive influence on other members — staff-nominated |
| Freedom Lifestyle Achievement | Member who achieves a meaningful life milestone (travel, quit job, etc.) |
| $1M Funded | Cumulative $1M in prop firm capital under management |

**Award delivery:** Public post in the primary community channel + optional Telegram announcement.
Winners receive: Discord badge, milestone board permanent entry, featured content for social proof.

## Gamification System

Progress should be visible. Members should feel momentum at every stage.

### Discord Role Progression

```
🔰 New Member          → Joined, intro not posted
📖 4x Prophet Member   → Intro + goals posted, orientation complete
📊 Strategist          → Phase 02 complete (60-day journal, 80% process adherence)
⚔️ Funded Trader       → Active funded account confirmed
🔱 Operator            → Phase 04 complete — full Operator Status
🏆 Community Ambassador → Leadership role — contribution + nomination
👑 HTBB Legend         → Rare, permanent, nomination-based
```

- Daily journal entry: 1 point
- Posting a trade review with full format: 3 points
- Helping another member in #questions: 2 points
- Attending a live call: 5 points

- Posting accountability result: 2 points

Monthly leaderboard posted in #milestone-board. Top three recognized publicly.

## Community Challenge Framework

Challenges create shared experience, engagement spikes, and visible progress.

**Challenge structure:**

```
CHALLENGE NAME:     [e.g., "30-Day Discipline Protocol"]
DURATION:           [X days]
OBJECTIVE:          [Specific measurable activity — not outcome]
RULES:              [3–5 clear rules]
TRACKING:           [How members document progress — daily post / log / screenshot]
RECOGNITION:        [What happens at completion — role, badge, award]
SOCIAL:             [Encourage posting progress in dedicated thread]
```

**Example challenges:**
- 30-day trade journal streak (document every session)
- 10-trade execution challenge (execute 10 setups with full review for each)
- Prop firm simulation challenge (3 weeks of challenge rules on demo or live)
- Morning routine challenge (30 days of documented morning protocol)
- Screen time reduction challenge (trading hours only for 2 weeks)

Challenges must be about **process and discipline** — never about P&L targets.
