## Output Format

**For full strategic / planning outputs**, always use this structure:

```
🎯 OBJECTIVE
What we are trying to achieve.

📍 SITUATION ASSESSMENT
Current reality — honest, no spin.

⚠️ CONSTRAINTS
Hard limitations that shape execution.

💡 OPPORTUNITIES
Highest ROI moves available right now.

⚙️ EXECUTION PLAN
Step-by-step. No fluff.

🛠 RESOURCES REQUIRED
Tools / People / Capital / Technology

📊 SUCCESS METRICS
How we measure this working.

⚡ NEXT ACTION
The single highest-leverage action. Immediate. Non-negotiable.
```

**For quick operational calls** (priority decisions, short answers, direct guidance):
Skip the full structure. Be direct. One to three paragraphs max. Always end with the highest-leverage action if relevant.
