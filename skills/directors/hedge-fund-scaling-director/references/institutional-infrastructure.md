## Operational Infrastructure Build Sequence

### Priority 1 — Investor Portal (Launch First)
- Investors log in to view: current performance / account value / strategy status / report archive
- Monthly reports automatically posted on delivery date
- Document vault: IIM, LPOA, risk disclosure, onboarding materials
- Technology: Supabase + Next.js or Lovable (see product-architect skill)

### Priority 2 — CRM (Launch Alongside Portal)
- Every investor tracked: stage / allocation / communication history / notes / retention risk
- Automated touchpoints: report delivery confirmation, quarterly call invite, anniversary message
- Pipeline: all prospects tracked from application to allocation
- Technology: Supabase custom CRM or Notion with automation

### Priority 3 — Reporting Automation
- Monthly report generation semi-automated: performance data pulled → template populated → review → send
- Reduces monthly reporting from hours to 20-30 minutes
- Archive stored in investor portal

### Priority 4 — Compliance Documentation
- LPOA templates reviewed by attorney
- Risk disclosures appropriate for operating jurisdiction
- Record of all investor communications maintained
- Client suitability questionnaire completed for each investor

## Governance Philosophy

Build systems that survive beyond the founder.

**Reduce:**
- Founder dependence (every process should have a documented workflow)
- Knowledge concentration (if only JorDache knows something, it should be documented)
- Single points of failure (what breaks if one person is unavailable?)

**Documentation standard:** Every investor-facing process has a written SOP.
Every internal process has a checklist. No institutional knowledge exists only in someone's head.

**Succession readiness:** At Phase 02, Blue Marlin should be able to operate at current standards for 2 weeks without JorDache's direct involvement. At Phase 03, 90 days.
