# 4x Prophet 2.0 — The Operator System Curriculum

## Framework Overview

All education maps back to one framework: **4x Prophet 2.0 — The Operator System.**

Three layers. Fifteen modules. One destination: Operator Status.

---

## Layer 01 — Technical Foundation (Modules 01–08)

**Goal:** Build the mechanical competency to read and execute in institutional markets.

| Module | Focus |
|---|---|
| 01 | Market Structure — how price moves, swing highs/lows, trend identification |
| 02 | Liquidity — buy-side/sell-side pools, stop hunts, liquidity engineering |
| 03 | Volatility — regime identification, session volatility profiles, expansion vs. contraction |
| 04 | Institutional Concepts — order blocks, fair value gaps, displacement, imbalance |
| 05 | Execution Models — entry frameworks, confirmation triggers, timing models |
| 06 | Trade Management — partials, BE protocol, trailing, position management under pressure |
| 07 | Risk Management — position sizing formula, max daily/weekly DD rules, psychological limits |
| 08 | Session Analysis — Asia/London/NY behaviors, session-specific setups, overlap dynamics |

**Layer 01 completion standard:** Student can identify setup, articulate thesis, define entry, set stop, and project targets — without prompting.

---

## Layer 02 — Macro Engine (Modules 09–10)

**Goal:** Understand the forces that move Gold above the 4H chart.

| Module | Focus |
|---|---|
| 09 | Macro Drivers — real rates, DXY correlation, US10Y, CPI/PCE impact, Fed policy |
| 10 | Gold Frameworks — COT positioning, ETF demand, central bank demand, physical demand, seasonal tendencies |

**Layer 02 completion standard:** Student can articulate weekly Gold bias using macro context — not just technical levels.

---

## Layer 03 — Workflow & Capital (Modules 11–15)

**Goal:** Operate like a professional trader and begin building capital infrastructure.

| Module | Focus |
|---|---|
| 11 | Weekly Planning — bias development framework, planning session structure, preparation ritual |
| 12 | Funded Accounts — prop firm selection, challenge strategy, consistency rule (40%), payout structure |
| 13 | Copy Trading — how to evaluate, subscribe, and use copy trading as a supplementary tool |
| 14 | Business Development — turning trading skills into income streams, brand building basics |
| 15 | Capital Allocation — from funded profits to personal capital, scaling strategy, 4x Heist ecosystem |

**Layer 03 completion standard:** Student has active prop firm challenge in progress and a weekly trading routine documented.

---

## Progression System

### Phase 01 — Discipline & Execution
**Focus:** Building the foundational habits and mechanical skills.
**Milestone:** Complete Modules 01–04. Trade journal active for 30 days. No significant process violations.
**Recognition:** "Foundation Builder" Discord role.

### Phase 02 — Strategy & Consistency
**Focus:** Applying the full technical framework with documented consistency.
**Milestone:** Complete Modules 05–10. 60-day trade journal. Minimum 80% process adherence.
**Recognition:** "Strategist" Discord role.

### Phase 03 — Funded Trader Path
**Focus:** Executing within prop firm constraints. First funded account.
**Milestone:** Complete Modules 11–12. Active funded account or first prop firm pass.
**Recognition:** "Funded Trader" Discord role + community announcement.

### Phase 04 — Operator Status
**Focus:** Independent operator. Multiple income streams. Capital building.
**Milestone:** Consistent funded profits + first payout + Layer 03 complete.
**Recognition:** "Operator" Discord role. Eligible for mentorship referral program. HTBB Legend potential.

## Content Philosophy for HTBB

Content should: Educate / Challenge / Inspire action / Build trust / Demonstrate expertise / Show real operators / Show real results.

**Content should not:** Hype unrealistic outcomes / Focus on capital performance metrics (no AUM, no % returns in community-facing content) / Position copy trading as passive income.

## Weekly Call Structure

### Trading Call (Weekly)
- Market environment overview (10 min)
- Liquidity map for the week (15 min)
- Setups for the week with full thesis (20 min)
- Q&A (15 min)

### Training Class (Weekly)
- Rotating through curriculum modules
- Case studies from recent price action
- Member trade reviews (with permission)
- Execution correction sessions
